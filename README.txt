IMPORTANT NAVIGATION
--------------------

All pages open in the SAME browser tab.

The project intentionally does NOT use:

target="_blank"

Therefore:

Home → Banking

Banking → Virtual Bank

Virtual Bank → Investments

Investments → Market

Market → Quiz

etc.

all happen in the same browser tab.

HOW TO RUN
----------

1. Install VS Code.

2. Open the BankWise_Standalone folder.

3. Install the VS Code extension:

Live Server

4. Open index.html.

5. Right-click index.html.

6. Select:

Open with Live Server

7. The website will open in your browser.
